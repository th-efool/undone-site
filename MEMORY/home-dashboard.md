# Home dashboard

- Composition: `src/app/(dashboard)/home/page.tsx` supplies authoritative active/paused/completed arrays, including empty arrays. Hidden user subscriptions are excluded before projection.
- UI: `src/client/screens/dashboard/home/HomeDesktop.tsx` combines active cohorts first (sorted by rank 1..N) and paused cohorts pushed to the far behind (ranks N+1..N+M). `components/ActiveCohorts/SubscribedCohortCard.tsx` uses a real navigation link, top-left 1-click play/pause toggle button (active shows Play ▶, paused shows Pause || in orange, no text badge), and top-right kebab menu (Edit, Pause options…, Delete).
- Card popovers portal into document.body, clamp to the viewport, and dismiss on outside pointer/Escape. Pause presets (1 day/1 week/custom date) live under Pause options… in the kebab menu. Custom dates cover the selected local calendar day; resume timestamp is local midnight on the following day. No time input.
- User settings: `hooks/useHome.ts` and `utils/cohortManagement.ts` rearrange cohorts on pause (pushing paused items to the far end behind all active cohorts and re-indexing active items 1..N) and on resume (inserting resumed items at the end of the active group in front of all paused items). Pause/resume applies optimistically (<16ms) to local state and local storage with immutable snapshot rollback on network failure; resume explicitly clears pausedUntil. Subscription and learning-setting mutations reject unauthenticated sessions rather than accepting local-only changes. Expired pauses restore on a timer.
- Removal: DELETE `/api/cohort/[id]/join` persists user-scoped Mongo `UserCohortConfig.isHidden` and removes only that user's Postgres membership. Cohort content and progress are retained. Home/feed exclude hidden subscriptions; POST join clears the marker. Mongo visibility is rolled back if membership deletion fails.
- Storage: `src/client/repositories/homeStorageAdapter.ts` must persist empty choices and honor hidden markers, including removal of the final cohort. Server-supplied lists take precedence over stale browser choices.
- Focused checks: `npx vitest run src/client/screens/dashboard/home/components/ActiveCohorts/__tests__/SubscribedCohortCard.test.tsx src/app/api/cohort/[id]/join/route.test.ts`.
