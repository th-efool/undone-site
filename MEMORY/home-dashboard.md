# Home dashboard

- Architecture & Projection: `src/server/domain/home/home.service.ts` (`loadHomeForUser`) provides authoritative active, paused, and completed cohorts. Cohort completion is strictly derived from MongoDB `UserChunkProgress` via pure `retainedLessonCompleted` predicate: a retained lesson is completed ONLY if every unique retained chunk ID has matching completed progress. Malformed chunk IDs are marked incomplete. SQL `LessonProgress` is only used as a legacy fallback for legacy chunkless lessons. Missing or failed DB reads throw truthfully without swallowing into fake 0% progress, mock cohorts, or synthetic streaks.
- Loading & Error Boundaries: `src/client/screens/dashboard/home/HomeLoading.tsx` is an inert presentational skeleton (`role="status"`, `aria-label="Loading dashboard"`) used by `src/app/(dashboard)/home/loading.tsx` and `page.tsx` React Suspense boundary without invoking `useHome` or triggering storage/network side-effects. `src/app/(dashboard)/home/error.tsx` catches data failures, displays an honest message, and provides an accessible retry button without exposing internal database details.
- Mutation Synchronization & Rollback Guard: `src/client/screens/dashboard/home/hooks/useHome.ts` enforces synchronous `mutationPendingRef` guard: concurrent actions in the same tick are immediately rejected with `'A change is still saving. Please wait.'`. Manages single atomic `cohortsState` to eliminate split active/continueLater intermediate states. Server prop updates are ignored while mutations are in-flight; successful mutations trigger `router.refresh()`. Account switching is guarded via user generation tracking to prevent stale in-flight requests from persisting across logout/login.
- Durable Server Ordering: `/api/user/cohort-config` and `src/server/domain/home/cohortOrder.service.ts` handle atomic membership state changes (`pause` and `resume`) and batch reordering inside MongoDB session transactions. `normalizeCohortId` strictly strips the `${userId}_` prefix without stripping valid IDs containing underscores. Active cohorts are assigned contiguous ranks `1..N`; paused cohorts are placed behind at `N+1..N+M`. Expired pause timestamps are restored immediately as active.
- Desktop & Mobile Feature Parity: Both `HomeDesktop.tsx` and `HomeMobile.tsx` consume pure `getSubscribedCohorts` ordering helper, shared `ActiveCohorts`, and `SubscribedCohortCard`. Mobile supports full pause, resume, edit, delete, learning settings modal, and `ChannelHub` tuning with accessible labels. Search input (`aria-label="Search cohorts"`) filters both active and paused cohorts with distinct `No matching cohorts found.` state. Action buttons are disabled (`aria-disabled="true"`) and card shows `role="status"` while a save is pending, preserving navigation link functionality.
- Truthful Supporting Widgets:
  - `HomeStreakWidget`: Omits fake 12-day streak and fabricated minutes when activity statistics are unavailable, showing neutral learning encouragement.
  - `HomeStudyRooms`: Dedicated component fetching live `/api/studyroom?format=v2&tab=discover&limit=4`, displaying honest room occupancy and links to `/studyroom/<slug>`. Empty state links to `/studyroom`.
  - `UpcomingEvents`: Initializes from learner's local date/time, updates at local midnight, retains `useUnifiedTasks`, and clearly disables unintegrated calendar providers (Google, Outlook, Apple) with `Coming later` badges.
  - `ChannelHub`: Unconsumed automation settings (weekly goal, learning allocation, reminder window) are disabled with `Coming later`, keeping working channel sliders fully functional.
