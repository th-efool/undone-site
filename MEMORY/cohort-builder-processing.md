# Cohort builder processing

- Interactive chat uses `COHORT_CHAT_MODEL` (default `gemini-3.5-flash-lite`) separately from processing model selection. `interactionModel.ts` bounds a turn to 20s/1200 output tokens with zero SDK retries; adapter policy remains optional for other consumers. Initial topic replies avoid redundant metadata tools. `UNDONE_LOG_LEVEL` controls server operational logs (default INFO); browser logs remain opt-in in production. Correlate model_started/completed/failed by runId/workspaceId; queueWaitMs is logged on claim.

- `src/server/domain/cohort-builder/text-job-plan.ts`: source DAG (acquisition -> optional extraction -> understanding -> chunking -> analysis -> global assembly). Algorithm keys version downstream work independently; keep acquisition identities stable to reuse retained paid work.
- `text-source-processor.ts`: per-source artifact payloads are arrays for understanding/chunks/analysis. `text-job-acceptance.ts` locks current workspace/graph, validates artifact source/version and deterministic prerequisite bytes, accepts with lease fence, then commits intermediate snapshot + job status atomically. `text-assembly-acceptance.ts` separately validates final lesson projection and moves journey to ready.
- `text-pipeline.ts`: timed observations grouped toward 60 seconds; final remainder allowed, 24 KiB Unicode-safe evidence bounds, complete non-whitespace character coverage. Byte limits can require shorter units. Evidence offsets/checksums remain exact; playback overlap never modifies retained evidence.
- `src/shared/cohort-builder/cohort-metadata.ts`: browser-safe deterministic concept/title/description/chunk display helpers. A video source projects as one learner lesson with ordered evidence parts. The source-level playback plan spans from zero through verified duration, assigns observation gaps to the preceding playable part, and adds 15 seconds of real overlap before the next part; retained evidence remains unmodified. Missing timing is not replaced with invented offsets.
- `source-adapters.ts`, `journey-video-adapter.ts`, `youtube-transcript.ts`: retain video title/duration in optional provenance fields. Existing snapshots without these fields remain valid. `src/server/domain/cohort-creation/material-observation.ts` rejects invalid/overlapping intervals; provider repair must not silently clip/drop evidence.
- `src/shared/cohort-builder/delivery.ts`: uses shared metadata/interval helpers and the same deterministic per-source score context as analysis preview. `src/server/domain/cohort-builder/release.ts`: hashes resolved generated title/description.
- `src/client/screens/cohortBuilder/ChatPane.tsx`: four-stage checklist while processing/ready. `CohortWorkspacePane.tsx` stepper supports saved-stage inspection without reprocessing. `stages/ProcessingFailures.tsx` shows actionable failures only; stage views keep normal machine job rows out of learner-facing progress.
- Checks: `npx vitest run src/server/domain/cohort-builder/__tests__/text-pipeline.test.ts src/server/domain/cohort-builder/__tests__/text-job-acceptance.test.ts src/server/domain/cohort-builder/__tests__/text-assembly-acceptance.test.ts src/server/domain/cohort-builder/__tests__/youtube-canonical-jobs.test.ts src/server/infrastructure/ai/__tests__/vercelMaterialObservation.test.ts src/shared/cohort-builder/__tests__/cohort-metadata.test.ts src/client/screens/cohortBuilder/__tests__/processing-details.test.tsx`; `npx tsc --noEmit --incremental false`.

- Conversational co-design: `context.ts` reserves community search for explicit requests and includes presentation plus lesson objectives. `tools.ts` exposes shared metadata/source/authoring tools in chat/review/goal_setup/material_input; `draft_curriculum` appends through ordered, journaled `add_lesson` commits (partial drafts remain if a later commit fails). Presentation uses `learningOutcomes`/`requirements`, persona uses `set_audience`.
- `contracts.ts`: chat supports direct branch selection; planning stages support goal/material processing and explicit discovery without prior wizard navigation. First manual lesson in chat opens review; ready status never masks queued/running work. Source validation, owned upload checks and revision fencing remain authoritative. `planCohortAction` excludes action discriminator `type` before spreading presentation object, keeping presentation snapshots strictly valid. Activity route (`route.ts`) computes full SHA-256 ETag from `{ turns }` payload, preventing 304 stale-turn caching on failed runs. `ChatPane.tsx` renders transcript only; planning chips use intent, lessons and the latest assistant text, positioned above composer and hidden during active turns.
