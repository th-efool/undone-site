# Play playback & screen architecture

- `src/app/(dashboard)/play/page.tsx`: Route entry for `/play`. Parses feed query parameters (`cohortId`, `lessonId`, `chunkId`, `channel`), mounts `FeedProvider`, delegates conditionally to `PlayScreen` (desktop) and `PlayMobile` (mobile viewports).
- `src/client/screens/dashboard/play/PlayScreen.tsx`: Desktop visual composition matching the cinematic reference. Near-black `#08090C` canvas, top feed-position indicator capsules, top metadata row with honest course/episode indicator, centered media surface with restrained corners, edge previews for previous/next items, left navigation rail, right learning-tools rail, and detached bottom dock.
- `src/client/screens/dashboard/play/hooks/usePlayback.ts`: Shared playback engine. Manages exact index navigation (`goToIndex`), chunk start/end normalization, per-channel abort controller lifecycle to prevent nested update depth recursion loops, provider control adapters (HTML5 `<video>` and YouTube iframe), volume and mute restore, playback speed capabilities, boundary enforcement (pausing HTML5 video at `endSecs`), and bounded POST exclusion continuation protocol with `servedChunkIds: string[]` (max 5,000 items) replacing fragile offset pagination. Pre-fetches continuation when queue falls below 3 items.
- Selection Priority & Replay: Explicit `requestedChunkId` parameters are identified before frontier/completion filtering, added to candidate chunks even if completed, and structurally placed at index 0 in the interleaver. Revival fallback is removed; empty feeds are truthfully returned when no authorized content is eligible.
- Completion Persistence & Acknowledgment: Optimistic progress updates validate that server response contains `{ success: true, progress: { chunkId, status: 'COMPLETED' } }`. On HTTP failure or malformed payload, optimistic progress is immediately rolled back and surfaced to the UI.
- Canonical Cache & Preferences: Persisted caches are versioned under `sidequest_feed_cache_v2:` with explicit selection change invalidation. User channel preferences are stored and hydrated under user-scoped canonical document `sidequest_channel_config_v2:<userId>` with serialized 500ms debounced saves and `keepalive: true` unmount flushing via `homeStorageAdapter`.
- `src/client/mobile/screens/Play/PlayMobile.tsx`: Responsive mobile layout supporting portrait and landscape orientations, safe-area padding, accessible touch targets (>=44px), and bottom drawer sheets for deferred/secondary tools.
- Scope Boundaries: Notes, annotations, capture, microphone, report submission, and captions are strictly deferred. Visual controls are rendered in place with `aria-disabled="true"` and explanatory tooltips ("coming later"). No notes APIs, autosave, annotation synchronization, or database schemas are modified.
- Checks: `npx vitest run src/client/screens/dashboard/play/hooks/ src/app/api/feed/ src/server/domain/feed/ src/server/domain/progress/ src/app/api/progress/chunk/`; `npx tsc --noEmit --incremental false`.
